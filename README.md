# WHALE生物样本扫码入库管理系统

一个面向 -80℃ 冰箱生物样本入库场景的浏览器端登记系统。系统支持先上传样本清单，再用扫码枪逐支扫描样本编码；匹配成功会自动标记样本已入库，未匹配或重复扫码会给出醒目提示、声音报警并记录日志。数据保存在浏览器 `localStorage` 中，刷新页面后仍可继续当前入库任务。

## 功能

- 上传 `.xlsx` / `.xls` / `.csv` / `.txt` 样本清单。
- 自动识别第一列或 `样本编号`、`sample_id`、`barcode`、`sample barcode`、`id` 等表头列作为候选入库样本编号。
- 保留上传清单中的其他原始字段，并在导出结果时追加到 CSV 末尾。
- 扫码匹配样本清单，成功后标记“已入库”。
- 扫码成功、重复扫码、未匹配样本时分别展示醒目成功、警告、错误提示。
- 支持选择样本类型（血浆、白膜层、血清、全血、DNA、RNA、组织、其他）。
- 支持记录样本来源；选择“测序返回样本”后可填写返回公司名称。
- 同一盒内扫码后盒内位置自动递增：10×10 样本盒按 `A1` → `A2` → ... → `A10` → `B1` 递增，9×9 样本盒按 `A1` → ... → `A9` → `B1` 递增。
- 展示当前盒已入库样本数量和下一盒内位置。
- 支持撤回已扫码入库记录：扫码区提供醒目的“撤回上一支”按钮和“最近扫码撤回”记录，样本清单状态表中也可对任意已入库样本点击“撤回”，撤回后样本恢复为未入库并可重新扫码。
- 点击“完成当前盒并开始下一盒”后，盒号会自动按末尾数字递增（如 `BOX-001` → `BOX-002`、`BOX-2026-009` → `BOX-2026-010`），盒内位置回到 `A1`。
- 冰箱存放位置会在完成当前盒后自动跳到下一格，并按“格子 → 抽箱 → 列 → 层架 → 冰箱”的顺序进位。
- 按盒记录冰箱位置：冰箱 `001/002`、4 个层架、每层 5 列、每列 5 个抽箱、每个抽箱 5 个格子。
- 实时统计清单样本、已入库、未入库、异常扫码数量。
- 导出 CSV 字段包含：样本编号、条码、入库状态、样本类型、样本来源、返回公司、冰箱、层架、列、抽箱、格子、盒号、样本盒规格、盒内位置、完整位置、扫码时间，并追加上传清单原始字段。
- 清空扫码日志、重置任务前均进行二次确认。

## 本地运行

### Windows 推荐方式

1. 安装 Python 3，并确认 `python` 命令可用。
2. 在项目目录打开 PowerShell 或命令提示符。
3. 运行：

```bash
python -m http.server 5173
```

4. 在浏览器打开 `http://localhost:5173`。

### macOS / Linux 或 npm 方式

```bash
npm run start
```

启动后在浏览器打开 `http://localhost:5173`。如果系统没有 `python3` 命令，也可以直接使用 Windows 推荐方式中的 `python -m http.server 5173`。

## 使用流程

1. 点击“上传样本清单”，选择 Excel、CSV 或 TXT 文件。
2. 在“当前盒号/名称”中填写盒号，或使用默认 `BOX-001`。
3. 根据样本实际情况选择样本类型；如为测序返回样本，选择“测序返回样本”并填写返回公司。
4. 确认盒内起始位置，例如 `A1`。
5. 选择当前盒子的冰箱、层架、列、抽箱和格子。
6. 扫码枪扫描样本条码；扫码枪回车会自动登记入库，并把下一盒内位置自动更新为 `A2`、`A3` 等。
7. 如发现扫错，可在扫码输入右侧点击“撤回上一支”，或在“最近扫码撤回”中撤回前面的扫码记录；下方样本清单表也支持对任意已入库样本撤回。撤回后该样本可重新扫码。
8. 当前盒扫码完成后，点击“完成当前盒并开始下一盒”；系统会自动递增盒号、盒内位置回到 `A1`，并将冰箱位置跳到下一格。
9. 全部完成后点击“导出结果 CSV”。
