# 生物样本扫码入库登记系统

一个面向 -80℃ 冰箱生物样本入库场景的浏览器端登记系统。系统支持先上传样本清单，再用扫码枪逐支扫描样本编码；匹配成功会自动标记样本已入库，匹配失败或重复扫码会声音报警并记录异常日志。

## 功能

- 上传 `.xlsx` / `.xls` / `.csv` / `.txt` 样本清单。
- 自动识别第一列或 `样本编号`、`sample_id`、`barcode` 等表头列作为候选入库样本编号。
- 扫码匹配样本清单，成功后标记“已入库”。
- 未匹配或重复扫码时弹出醒目提示并发出报警音。
- 按盒记录冰箱位置：冰箱 `001/002`、4 层、每层 5 列、每列 5 个抽箱、每个抽箱 5 个格子。
- 实时统计清单样本、已入库、未入库和异常扫码数量。
- 导出完整入库结果 CSV。
- 本地自动保存任务状态，刷新页面后仍可继续。

## 运行

```bash
npm run start
```

启动后在浏览器打开 `http://localhost:5173`。

## 使用流程

1. 点击“上传样本清单”，选择 Excel、CSV 或 TXT 文件。
2. 在“当前盒子编号/名称”中填写盒子编号，或使用默认 `BOX-001`。
3. 选择当前盒子的冰箱、层、列、抽箱和格子。
4. 扫码枪扫描样本条码；扫码枪回车会自动登记。
5. 当前盒扫码完成后，点击“完成当前盒并开始下一盒”。
6. 全部完成后点击“导出结果 CSV”。
